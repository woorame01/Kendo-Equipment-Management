# 검도부 장비 관리 시스템 (Kendo Equipment Management)

검도 동아리의 부원과 장비를 관리하기 위해 만든 Java 콘솔 프로그램입니다. 부원 정보와 장비 이용자를 연결하고, 장비별 상태와 수리 이력을 관리할 수 있습니다.

> 현재 데이터는 프로그램 실행 중 메모리에 저장됩니다. 데이터베이스나 파일을 통한 영구 저장 기능은 구현되어 있지 않습니다.

## 주요 기능

### 부원 관리

- 부원 등록 및 목록 조회
- 학번으로 부원 검색 및 삭제
- 이름, 성별, 학번, 전화번호 관리
- 부원 삭제 시 해당 부원이 사용하던 호구 삭제 및 수리 이력의 사용자 정보 제거

### 장비 관리

- 죽도, 호구, 호면, 호완, 갑, 갑상, 도복 등록 및 목록 조회
- 장비 검색 및 삭제
- 죽도와 호구 이용자 등록·변경
- 이용자가 지정되지 않은 장비 조회
- 장비 상태 등록 및 변경: 사용가능, 수리필요, 수리불가능, 폐기
- 죽도의 구성 부위별 상태 관리
- 호구에 호면·호완·갑·갑상을 연결하고 구성품 교체
- 구성품 상태를 반영한 호구 상태 확인

### 수리 이력

- 죽도 및 호구 구성품의 수리 일자, 내용, 결과 등록
- 장비별 수리 이력 조회

## 프로젝트 구조

```text
src/
├── KKC/
│   ├── KKC_System.java          # 콘솔 메뉴 및 프로그램 진입점
│   ├── KKC_Member.java          # 부원 데이터
│   └── KKC_Member_Manager.java  # 부원 등록·검색·삭제·목록 관리
└── Equipment/
    ├── KKC_Equipment.java       # 공통 장비 정보 및 상태
    ├── Equipment_Manager.java   # 장비 등록·조회·삭제·상태·이력 관리
    ├── Equipment_Status.java    # 장비 상태 값
    ├── Equipment_RepairHistory.java # 수리 이력
    ├── Equipment_Shinai.java    # 죽도 및 부위별 상태
    ├── Equipment_Hogu.java      # 호구와 구성품·이용자
    ├── Equipment_Homen.java     # 호면
    ├── Equipment_Howan.java     # 호완
    ├── Equipment_Gap.java       # 갑
    ├── Equipment_Gapsang.java   # 갑상
    └── Equipment_Dobok.java     # 도복
```

## 개발 환경 및 실행

- Java 25 (저장소의 Eclipse 설정 기준)
- Eclipse 프로젝트
- 패키지: `KKC`, `Equipment`

Eclipse에서 프로젝트를 가져온 뒤 `KKC.KKC_System`의 `main` 메서드를 실행하면 콘솔 메뉴가 시작됩니다.

## 학습한 내용

- 클래스와 객체, 생성자, 캡슐화
- `ArrayList`를 이용한 데이터 관리
- 클래스 간 참조와 객체 관계 구성
- 메서드와 패키지를 통한 역할 분리
- `enum`을 활용한 장비 상태 표현
- 콘솔 입력 처리와 예외 처리
- Git 및 GitHub를 이용한 버전 관리
